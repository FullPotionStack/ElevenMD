# A quieter place to write

This is **ElevenMD**. Familiar tabs. Local files. Markdown that looks like Markdown.

![ElevenMD's warm-paper writing palette](assets/elevenmd-paper.png)

Closing the window keeps all your tabs automatically. **Save** writes to the real file; closing does not. Settings shows where the private session lives.

Use **Insert image** to choose a local picture or enter an HTTPS URL. Local pictures are copied beside your Markdown document. Remote pictures load only if you enable them in Settings.

Spell check starts **off**. Light/dark/system themes apply immediately.

## The Windows-first alpha

- Write with **bold**, *italic*, and `inline code`
- Keep a few documents open in separate tabs
- Switch to source whenever you need the exact syntax
